CSV Format

First row must be headers. Required columns: Name, Birthday, Variety, PlantingDate. Recommended full format:

Name, Birthday, Commodity, FarmLocation, Area, Variety, PlantingDate

Format rules & tips
• Save from Excel as CSV UTF-8.
• Dates: use MM/DD/YYYY (other common formats like YYYY-MM-DD or "Jan 5, 2026" are also accepted).
• A row must have BOTH a variety and a planting date. Rows missing either are treated as not insured and skipped — if a farmer has no complete rows, the popup says the database will be updated (not on the list).
• Area is optional and shown exactly as typed (e.g., 1.5 ha or 2,500 sqm). A blank area shows “—”.
• FarmLocation is optional, shown in the popup table beside Commodity (e.g., Brgy. San Juan). A blank location shows “—”.
• Birthday confirms identity — each farmer is matched by first name + last name + exact birthday (middle name optional).
• A farmer may appear in multiple rows (e.g., different parcels / planting dates); up to 5 entries are shown per search.
• Rows with a missing name or an invalid birthday are skipped.
• "Lastname, Firstname" format is handled automatically.

Share with Farmers — Baked-in App

Download a copy of this app with the currently saved Rice and Corn databases and your popup messages embedded inside the file. Share that one file (free hosting like Netlify / GitHub Pages, Messenger, Bluetooth, USB) and farmers can search on their phones with no upload needed — it even works offline.

🔒 The exported farmer edition has the admin panel disabled and no password included — there is nothing to find or crack in the shared file. Update the data from your office copy and export again.

⚠ The data travels inside the shared file, so a tech-savvy person could extract it. Farmers themselves only ever see their own search results. If downloads are blocked in a preview frame, open the app in a full browser tab first.
